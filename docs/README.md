## What's New in v3.0

- **Watch Mode**: Auto-reload and rerun tests on file changes with `-w/--watch`
- **CLI Improvements**: Progress bar, quiet mode, and test results file output
- **Bail on Failure**: Stop test runs early with `--bail`
